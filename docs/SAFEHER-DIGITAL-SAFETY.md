# Digital Safety centre

## Visitor walkthrough

Open /digital-safety and choose Protect my accounts, Someone is bothering me, or Help a friend. Each starting point links to a section on the same page. Expand a topic to read the related lesson, check its source and review information, then continue to its reflection question. Support links remain available without an account. Offline saving is available from the lesson page.

The blackmail topic links to preparation for trusted support. The grooming topic links to the pressure/control lesson. Their introductions describe that limited scope; neither is presented as a specialist assessment or a dedicated treatment of the concern.

## Publication and review

The page now reads from approvedLessons(), which applies the same publication, locale, review-scope and expiry rules as the learning hub. It displays lesson source, actual review date, expiry and version. There is no hardcoded review date. Missing, withdrawn or expired lessons have an unavailable state with alternative links. Database failure produces a page alert while retaining navigation and support access.

Expandable lesson paragraphs are read directly from the published records. The public page does not change any content or approval status. Starting-point headings and context notes are interface copy and require separate qualified review, particularly the blackmail and grooming scope notes and monitored-device notice. Review metadata refers to the lesson text, not professional approval of every interface label.

Use the existing [learning review handoff](SAFEHER-LEARNING-REVIEW.md) and reconcile the exact database versions before professional sign-off. Do not claim professional approval or source endorsement based on an interface update.

## Verification scope

Check all three anchor destinations, keyboard operation of native details/summary controls, current review metadata, absent-lesson handling, database failure, source and lesson links, mobile overflow and accessibility. Confirm no settings, answers, or disclosures are collected by this page. No account, local storage, or new submission endpoint is required for these controls.

Local verification passed ESLint, Next route type generation, TypeScript, Prettier and whitespace checks. Chrome checks using a temporary fixture page passed all three anchor links, keyboard expansion of all six topics, actual supplied review fields and lesson destinations. At 1440px and 390px, there was no horizontal overflow and axe reported no WCAG 2 A/AA or WCAG 2.1 AA findings within main content. Unavailable lesson records showed alternative learning links, an outage alert and an accessible support link without dead lesson destinations. The fixture route was removed before release.

These checks use synthetic lesson fixtures because the local database is unavailable. They do not establish professional approval, provider availability, full offline operation or accessibility certification. Screenshots are in test-results/digital-safety.
