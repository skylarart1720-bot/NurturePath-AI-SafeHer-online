## Implementation and maintenance

The additive migration adds public telephone/email fields, service/contact-option tags, and the verification method. It removes no existing records. Run `npm run directory:seed` after migrating and provisioning an administrator. The import records an audit entry under the active administrator, preserves later edits and revoked verification, and refuses an evidence snapshot older than 180 days. It does not recheck sources automatically or change the review date on each run.

The public directory defaults to current real listings. Synthetic examples remain in the database and can be explicitly included for evaluation. Missing, future-dated, or expired checks are excluded from real listings. Administrators must recheck source details before approving another review date. Every change to a provider entry invalidates the previous check.

Before contact options are revealed, users see what an external contact can disclose and acknowledge the limits. Phone/email links contain only the published address or number; no question, account identifier, disclosure, or referral payload is attached. Automated referral transmission remains disabled.
